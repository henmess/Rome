# הטיול שלנו לרומא 🏛️🎄

אתר עם המסלול הזוגי לרומא (20–23 בדצמבר 2026), הכול ברגל ובתחבורה ציבורית:
לו״ז יומי, מפה עם מסלולי ההליכה, מסעדות, רשימת הזמנות, מזג אוויר, עלויות ומספרי חירום.

## צפייה
- לפתוח את `index.html` בדפדפן, או
- להפעיל GitHub Pages: Settings → Pages → Deploy from a branch → בוחרים את הענף ואת התיקייה `/ (root)`.

## להשלים
- **מחירים:** טיסות $384 (לשנינו) ומלון €686 (3 לילות, ארוחת בוקר וביטול חינם) כבר מוזנים בכרטיס "💰 עלויות". אפשר לשנות אותם באתר, והשינוי נשמר בטלפון.
- **שעת ההמראה מנתב״ג:** ב־`index.html`, במערך `TRIP_FLIGHTS` (השדה `tlvTime`). כשהשדה מלא, האתר משווה את השעה ללוח נתב״ג.
- **תמונת המלון:** שמים קובץ בשם `img/hotels/white.jpg`, והוא מוצג במקום התמונה מוויקיפדיה.
- **תמונת הרקע למעלה:** קובץ בשם `img/hero.jpg` (רצוי ברוחב 1,600 פיקסלים לפחות).
